# SystemVerilog Lab 14 - SystemVerilog Assertions (SVA)

This repository contains SystemVerilog source files for **Lab 14**, focusing on SystemVerilog Assertions (SVA), immediate assertions, and concurrent assertions for design verification.

---

## 📂 File Structure

| File Name | File Type | Description |
| :--- | :--- | :--- |
| **`assertions.sv`** | SystemVerilog Source | Implements general assertion constructs and verification checks. |
| **`concurrent_assert.sv`** | SystemVerilog Source | Demonstrates concurrent assertions for verifying temporal and sequential design behavior over clock cycles. |
| **`immediate_assert.sv`** | SystemVerilog Source | Illustrates immediate assertions for procedural and combinational condition checking. |

---

## 🚀 Getting Started

### Prerequisites
A SystemVerilog-compatible simulator supporting SVA (such as ModelSim, Questa, VCS, or Xcelium) is required to compile and execute these source files.

### Compilation & Simulation
1. Compile the chosen assertion source file in your simulator.
2. Run the simulation to evaluate assertion passes, failures, and check messages.
