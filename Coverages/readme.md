# SystemVerilog Functional Coverage Lab

This repository contains SystemVerilog source files focused on **Functional Coverage**, including covergroups, transition bins, illegal bins, cross coverage, and coverage testbench integration.

---

## 📂 File Structure

| File Name | File Type | Description |
| :--- | :--- | :--- |
| **`coverage_illegal.sv`** | SystemVerilog Source | Demonstrates the definition and tracking of illegal bins (`illegal_bins`) to catch invalid states or transitions. |
| **`coverage_tb_lab.sv`** | SystemVerilog Source | Implements a complete coverage testbench environment to sample and report coverage metrics. |
| **`coverage_transition.sv`** | SystemVerilog Source | Illustrates transition coverage (`transition bins`) to monitor sequential state changes over time. |
| **`cross_coverage.sv`** | SystemVerilog Source | Demonstrates cross coverage (`cross`) between multiple variables or coverpoints. |

---

## 🚀 Getting Started

### Prerequisites
A SystemVerilog-compatible simulator supporting functional coverage and covergroups (such as ModelSim, Questa, VCS, or Xcelium) is required to compile and execute these files.

### Compilation & Simulation
1. Compile the target coverage source file or testbench together in your simulator.
2. Run the simulation and view the functional coverage report generated by the tool.
