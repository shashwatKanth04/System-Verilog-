# SystemVerilog – Procedural Blocks & Statements

SystemVerilog programs demonstrating procedural constructs — combinational 
and latched processes, synchronous/asynchronous reset, and fork-join variants.

| File | Description |
|---|---|
| asyn_rst.sv | Asynchronous reset process example |
| sync_rst.sv | Synchronous reset process example |
| latch.sv | Latched process (level-sensitive logic) |
| mux_comb.sv | Combinational process — multiplexer |
| fork_join.sv | fork-join block (waits for all processes) |
| forkjoin_any.sv | fork-join_any variant (waits for any one process) |
| forkjoin_none.sv | fork-join_none variant (does not wait) |

**Concept covered:** Procedural blocks, combinational/latched/sequential processes, fork-join and its variants
**Status:** Lab exercises from PGCP-VLSI SystemVerilog module.
