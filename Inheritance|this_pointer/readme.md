# SystemVerilog Object-Oriented Programming (OOP) Lab

This repository contains SystemVerilog source files exploring Object-Oriented Programming (OOP) concepts, including class inheritance, handle assignments, and the use of the `this` keyword.

---

## 📂 File Structure

| File Name | File Type | Description |
| :--- | :--- | :--- |
| **`inheri_1.sv`** | SystemVerilog Source | Demonstrates basic class inheritance principles and child-parent class relationships. |
| **`inheri_2.sv`** | SystemVerilog Source | Explores advanced inheritance, method overriding, or extended class features. |
| **`obj.sv`** | SystemVerilog Source | Illustrates object creation, handle assignments, and shallow copying behavior. |
| **`this.sv`** | SystemVerilog Source | Demonstrates the usage of the `this` keyword to resolve scope and reference current object properties. |

---

## 🚀 Getting Started

### Prerequisites
A SystemVerilog-compatible simulator (such as ModelSim, Questa, VCS, or EDA Playground) is required to compile and execute these source files.

### Compilation & Simulation
1. Compile the specific file or files together in your simulator.
2. Run the top-level module to observe simulation results.
