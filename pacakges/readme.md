# SystemVerilog – Packages

SystemVerilog programs demonstrating package declaration and usage, including 
explicit and implicit import methods (Lab 01).

| File | Description |
|---|---|
| adder.sv | Adder design using package-declared types/parameters |
| explicitimport.sv | Explicit import of package items (`import pkg::item;`) |
| importpkg.sv | Package import example (wildcard import) |
| packages.sv | Package declaration with reusable definitions |

**Concept covered:** SystemVerilog packages, scope resolution, import mechanisms
**Status:** Lab 01 exercises from PGCP-VLSI SystemVerilog module.
